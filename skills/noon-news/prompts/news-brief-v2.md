# News Brief Prompt v2

> 这是 noon-news 的格式契约。运行时应直接读取预取 JSON，不重复调用工具、脚本或网络。

## 任务

基于脚本输出生成一条中文「📰 今日热点简报」。只输出最终正文，不输出执行过程。

## 数据使用

- `news_aggregator`：新闻聚合来源。
- `rss_summary`：RSS 补充来源。
- `aihot`：AI 主线优先使用的 AI HOT 数据。

汇总后去重。同一事件保留信息最完整且可追溯的一条。所有具体数字、人名、地点和动作都必须能在原始输出中找到。

## 固定结构

```markdown
📰 今日热点简报

### 今日要点
严格输出 4–5 条编号列表，概括全天最值得关注的事件。

### 分类详情

**① 国际要闻**
- **English Title**
  （中文短题）
  一句话事实描述。
  来源：[NS](原文链接) · [BBC](原文链接)

**② 宏观与商业**
...

**③ AI 主线**
...
```

## 今日要点规则

- 严格输出 4–5 条编号列表。
- 主题词为 2–6 个中文字符。
- 冒号后只写一句核心事实，控制在 20 字以内。
- 只写纯中文，不带英文和来源标签。

## AI 主线规则

- 以 `aihot.items` 为主信源，按真实 category 兼顾模型、产品、行业和论文。
- AI HOT 为空、失败或与其他新闻明显重复时，可以回退到 `news_aggregator.items` 中 `source` 含 V2EX 的条目，并标记 V2EX。
- 不要混入 GitHub Trending、Hacker News、Product Hunt 等其他 AI 来源凑数；不足时省略整段。
- 每类 2–3 条，AI 主线总计不超过 12 条。

## 格式规则

- 保持上面的行结构；来源必须是独立行。
- 不把来源链接并入事实描述行。
- 每条详情由英文标题、中文短题、事实句和来源行组成；中文标题直接写，不强行加括号。
- 来源 URL 使用脚本原始条目的 `link` 或 `url`，不得自行拼接或改写。
- 来源链接文本使用来源简写，长度控制在 2～8 个字；多个来源使用 ` · `。
- 事实句只写已发生事实，不使用“预计、可能、或将、趋势”等推断词。
- 信息不足时写“信息有限，待更多来源确认”，不要编造细节。
- 详情不足时可以少报或省略分类，不要用无关来源凑数。
- 所有来源失败时只输出：`⚠️ 午间简报获取失败，请检查网络`。

## Self-check

输出前逐条检查：

1. 每条事实是否能在脚本原始输出中找到依据。
2. 具体数字、人名、地名是否有原文支撑。
3. 来源简写是否对应真实来源。
4. 来源行是否仍然独立存在且位于该条最后。
5. 是否保留了原有章节顺序和换行结构。
