# Output Contracts

## agents-report

当前可见结构保持稳定：

```markdown
📡 **agents-radar 生态报告 | [日期]**

**🤖 AI 生态动态**
- ① ...（来源：[短标签](真实 URL)）
- ② ...（来源：[短标签](真实 URL)）
- ③ ...（来源：[短标签](真实 URL)）

---

[脚本渲染内容，原样插入；`codexradar.markdown` 自身包含 `**🧠 CodexRadar 智力效率**` 标题，不要重复添加]

---

**🔥 开源热点趋势**
- ① 总体趋势
- ② 总体趋势

分类标题
- 热门项目：...
- 其他项目：...
```

约束：

- AI 动态正文每条不超过 140 字。
- 来源文本 2～8 个字，URL 使用预取数据中的真实链接。
- CodexRadar 不在 Prompt 中重算。
- 开源趋势前两行不得写具体项目清单。
- 项目分类标题不是列表项。
- 每个项目分类固定两行项目内容。

## noon-news

当前可见结构保持稳定：

```markdown
📰 今日热点简报

### 今日要点
1. 主题词：一句话事实。

### 分类详情
**① 国际要闻**
- **English Title**
  （中文短题）
  一句话事实描述。
  来源：[NS](原文链接) · [BBC](原文链接)
```

约束：

- `今日要点` 严格 4–5 条。
- 主题词 2–6 个中文字符；事实句不超过 20 字；不带英文和来源标签。
- 来源必须是独立行。
- 只增加链接时，不改变标题、章节、换行和来源位置。
- 来源 URL 来自原始 `link` / `url` 字段。
- 事实句只写原文可核对的事实。

## 变更规则

输出格式属于公开接口。任何可见排版变更都必须：

1. 更新对应 Prompt 版本。
2. 更新本文档。
3. 更新 fixture / snapshot 测试。
4. 先给出渲染预览，再修改运行时任务。
